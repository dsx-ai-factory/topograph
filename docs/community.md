# Community

Join the [Kubernetes Slack workspace](https://slack.k8s.io/) to discuss
Topograph with the community:

- [#topology-aware-scheduling](https://kubernetes.slack.com/archives/C012XSGFZQE)
  for Topograph and topology-aware scheduling across the ecosystem
- [#gpu-nvidia](https://kubernetes.slack.com/archives/C09N46EFJR0) for NVIDIA
  GPU support on Kubernetes

When asking for help, include the Topograph version, provider, engine, deployment
method, expected behavior, and observed behavior. Remove credentials and other
sensitive information from configuration and logs before sharing them.

Use [GitHub issues](https://github.com/dsx-ai-factory/topograph/issues) for reproducible
bugs and feature requests. Follow the [contribution guide](https://github.com/dsx-ai-factory/topograph/blob/main/CONTRIBUTING.md)
when proposing a change. Report potential security vulnerabilities privately as
described in the [security policy](https://github.com/dsx-ai-factory/topograph/blob/main/SECURITY.md),
not in Slack or a public issue.
